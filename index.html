kasugai_canvas_webGIS

KASUGAI Canvas CDN ホスト版向け テストデータ（.kasc + DATA/）配信サイト

1. このサイトについて

データ（.kasc + DATA/）だけを GitHub Pages で配信し、 CDN エンジン（kasugai-canvas-web）からの ?kasc= 参照でブラウザ WebGIS として再生するテスト用データホストです。

仕組み・必須ファイル・追加方法の仕様は ブラウザ WebGIS（外部ホスト配信）ドキュメント を参照してください。以下はこのサイト固有の情報です。

3. 収録データ（default プロジェクト）

kasugai_canvas 同梱のサンプルプロジェクトをそのまま配信しています。 ローカルデータとリモート URL 直参照の両方を含み、主要な行タイプを網羅しているため CDN エンジン改修時の回帰確認に使えます。

4. 注意点

  • .kasc と DATA/ は同じフォルダに置く — DATA/sample.geojson 等の相対参照は .kasc のある URL を基準に解決されます。
  • CORS — GitHub Pages は Access-Control-Allow-Origin: * で配信されるため、 CDN エンジン（別オリジン）からの fetch がそのまま通ります。自前ホストに移す場合は CORS 設定が必要です。
  • スナップショット方式 — .kasc はエクスポート時点の状態です。 QGIS 側の編集は再エクスポート＋push で反映してください。
  • 大きなファイル — GitHub Pages の1ファイル上限は 100MB です。 大容量データは CDN/オブジェクトストレージ等を URL 直参照で使い分けてください。
  • localhost データの確認 — QGIS 側の geo_webview 内蔵サーバー （localhost:8089/export-data/）を ?kasc= に指定する確認も可能ですが、 自分の PC 上でのみ有効です（外部共有はこのサイト経由）。
