kasugai_canvas_weGIS

KASUGAI Canvas CDN ホスト版（kasugai-canvas-web）向けの テストデータ（.kasc + DATA/）配信サイトです。

1. これは何か

KASUGAI Canvas は エンジン（プレイヤー本体）とデータ（.kasc + DATA/）が分離した設計で、 ?kasc=<URL> で任意の場所のプロジェクトを再生できます。 正本リポジトリ kasugai_canvas ではエンジンとデータが一体のため、 「エンジン = CDN、データ = 外部ホスト」という実運用構成の動作確認がしにくい課題がありました。

このサイトは データだけを GitHub Pages で配信し、 CDN エンジンからの ?kasc= 参照が正しく動くかを検証するためのものです。

2. URL 形式


  

    
要素値意味

    

      <stage>
      stable（既定）/ unstable / latest
      CDN の配信チャンネル。stable=安定版・unstable=開発版・latest=stable へのリダイレクト
    

    

      <engine>
      cesium / maplibre / openlayers / leaflet / gsimaps
      再生に使う描画エンジン。cesium がメイン（3D・フル機能）、他は同じ .kasc を読む互換プレイヤー
    

    

      ?kasc=
      .kasc ファイルの URL（要 URL エンコード）
      このサイト上のプロジェクトを指定。相対参照は .kasc のある URL 基準で解決

5. テストデータの追加方法

  
再生に必要な最低限は .kasc ファイル1つだけです。必要なファイルと条件は以下の通りです。

  

    
ファイル必須条件

    

      <id>/kasugai_canvas.kasc
      必須
      ?kasc= で指定する本体。全レイヤーが URL 直参照ならこれだけで動きます
    

    

      <id>/DATA/
      条件付き
      .kasc 内で DATA/... 等の相対参照しているローカルデータがある場合のみ（.kasc と同じフォルダに置く）
    

    

      <id>/project.json
      任意
      プロジェクト名の表示に使用（無くても再生可）
    

    

      <id>/bookmarks.xml 等
      条件付き
      .kasc の bookmark: 等で参照される場合のみ
    

    

      projects.json への登録
      不要
      このページの一覧に出すためだけのもの。.kasc の直 URL を ?kasc= に渡せば登録なしで再生できます
    

  

  
    
    
  1. QGIS プラグイン geo_webview の Export で .kasc + DATA/ を出力
    2. 
    
  2. このリポジトリに <プロジェクトID>/ フォルダとして配置
    3. 
    
  3. 一覧に出す場合は projects.json に {"id": "...", "title": "..."} を追記して push（Pages に数分で反映）
    4. 
  

  
kasugai_canvas_weGIS/
├─ projects.json       # プロジェクトマニフェスト（一覧表示用・再生には不要）
└─ <id>/             # プロジェクト
   ├─ kasugai_canvas.kasc   # ← 再生に必須（これだけで動く）
   ├─ project.json          # 任意
   └─ DATA/                 # 相対参照データがある場合のみ
  


  
6. 注意点

  
    
    
  • .kasc と DATA/ は同じフォルダに置く —
      DATA/sample.geojson 等の相対参照は .kasc のある URL を基準に解決されます。
    • 
    
  • CORS — GitHub Pages は Access-Control-Allow-Origin: * で配信されるため、
      CDN エンジン（別オリジン）からの fetch がそのまま通ります。自前ホストに移す場合は CORS 設定が必要です。
    • 
    
  • スナップショット方式 — .kasc はエクスポート時点の状態です。
      QGIS 側の編集は再エクスポート＋push で反映してください。
    • 
    
  • 大きなファイル — GitHub Pages の1ファイル上限は 100MB です。
      大容量データは CDN/オブジェクトストレージ等を URL 直参照で使い分けてください。
    • 
    
  • localhost データの確認 — QGIS 側の geo_webview 内蔵サーバー
      （localhost:8089/export-data/）を ?kasc= に指定する確認も可能ですが、
      自分の PC 上でのみ有効です（外部共有はこのサイト経由）。
    •
